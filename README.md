# Mashuqul Chowdhury — Personal Portfolio Website

Personal portfolio website for **Mashuqul Chowdhury**, CRM Product Manager & Enterprise Cloud Voice / CCaaS Engineer with over 17 years in enterprise telecommunications, Amazon Connect, Genesys Cloud CX, and Salesforce Service Cloud Voice.

## Overview
This modern portfolio is built with Next.js, React, and Tailwind CSS. It highlights:
- **Professional Background & Narrative:** Over 17 years of experience in telecommunications and enterprise CCaaS/UCaaS engineering.
- **Interactive CCaaS Architecture Walkthrough:** Real-time visualization of carrier ingress, conversational AI, CRM routing, and telemetry data lakes.
- **Verified Career Timeline:** In-depth roles spanning Hyundai Capital Canada, VoiceBootcamp Inc, IP Core Network Solutions, L7Connect, and IBSYS Canada.
- **Featured Case Studies:** Detailed architectural writeups on Amazon Connect migrations, omnichannel conversational bots, and carrier-grade softswitches.
- **Skills & Certifications:** Comprehensive breakdown of platforms, serverless architectures, Cisco/AWS/Genesys certifications, and education.
- **Direct Contact:** Simple, direct email messaging and verified profile links.

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **UI & Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Typography:** Erode Serif

## Running Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
